# ShortlistAI 🚀
> **Beat the ATS & Land More Interviews** | AI-Powered Resume & Job Description Analyzer

ShortlistAI is a high-conversion Micro-SaaS built for job seekers to test their resume against Applicant Tracking Systems (ATS) like Workday, Greenhouse, and Taleo in under 30 seconds.

---

## ⚡ Core Features
- **Instant ATS Scoring Engine (0-100%)**: Evaluates keyword density, formatting compliance, and impact metrics.
- **Skill Gap & Missing Keywords Map**: Highlights missing critical skills with 1-click copy.
- **AI STAR Bullet Point Optimizer**: Transforms passive bullets into high-impact, quantified metrics using the Google XYZ formula.
- **1-Click Test Drive**: Pre-filled sample resume and job description to test without friction.
- **Monetization Ready**: 
  - Free Scan (Viral acquisition lead magnet)
  - ₹99 ($4.99) 24-Hour Job Sprint Pass
  - ₹299 ($12.99) Pro Monthly Subscription
  - UPI (GooglePay / PhonePe / Paytm) & Card checkout simulated & ready for Razorpay/Stripe.

---

## 🛠️ Tech Stack
- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Animations & Effects**: Canvas Confetti
- **Deployment**: Vercel (Zero Server Maintenance, 100% Free Tier)

---

## 🚀 How to Run Locally
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 🌐 Deploy Live to the Internet in 2 Minutes
1. Push code to GitHub:
   ```bash
   git init
   git add .
   git commit -m "Launch ShortlistAI MVP"
   ```
2. Go to [Vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Import your GitHub repository and click **Deploy**.
4. Your live URL will be active immediately (e.g. `https://shortlistai.vercel.app`)!
